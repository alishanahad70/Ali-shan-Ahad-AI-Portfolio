# Ali-shan-Ahad-AI-Portfolio
Comparative Analysis
Applied Artificial Intelligence – Project Portfolio

This portfolio showcases a series of projects completed throughout my Applied Artificial Intelligence coursework. Each project highlights a different area of modern AI—including deep learning, computer vision, and generative modeling. Collectively, these works demonstrate hands-on experience with model development, experimentation, and evaluation using Python, TensorFlow, Keras, NumPy, and related tools.

📁 Project Folders & Descriptions
1. MNIST Convolutional Neural Network (CNN) Classifier

Folder: MNIST_CNN/

This project walks through the complete process of designing and training a CNN to classify handwritten digits from the MNIST dataset.

Key skills and concepts:

Loading and preprocessing numerical image data

Building and understanding CNN architecture

Using activation functions, pooling layers, and dropout

Training the model and evaluating accuracy

Adjusting hyperparameters to improve performance

Analyzing results and interpreting model behavior

This project establishes the foundations of deep learning and image recognition.

2. VGG16 Pretrained Model Experiment

Folder: VGG16_Lab/

This module focuses on applying the pretrained VGG16 model (trained on ImageNet) to classify images and explore transfer learning.

Key learning areas:

Using pretrained networks for feature extraction

Understanding transfer learning workflows

Observing how image modifications influence predictions

Examining the effects of rotation, noise, and distortions

Interpreting shifts in model confidence

This lab builds intuitive understanding of how deep models perceive and process images.

3. Diffusion Model – Image Generation

Folder: Diffusion_Model/

This project implements a simplified diffusion model capable of generating MNIST-like images from random noise.

Core concepts covered:

Forward diffusion and noise injection

Reverse denoising and reconstruction

Generating sample images through iterative refinement

Visualizing the full generative pipeline

Understanding the foundation of modern generative AI systems

This assignment introduces the principles behind diffusion-based generative models, a cornerstone of today’s advanced AI image generators.

🧠 Skills Demonstrated

Convolutional Neural Networks (CNNs)

Transfer Learning with VGG16

Generative AI using Diffusion Models

Data preprocessing and normalization techniques

Model training, tuning, and visualization

Interpreting model confidence and debugging incorrect predictions

Proficiency with Python, TensorFlow/Keras, NumPy, and Matplotlib
